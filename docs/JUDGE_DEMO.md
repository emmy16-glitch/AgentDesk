## 90-second core story

1. **Thesis** — “Don’t trust the listing. Test the agent.”
2. **Task first** — enter one concrete DeFi task.
3. **Real discovery** — point out the ERC-8004 IDs/source links and explain that registry presence is not liveness.
4. **Live audition** — run compatible candidates and let timeout/unsupported states remain visible.
5. **Comparison** — show the result type, Task Fit and evidence. Emphasize that no fabricated global Trust Score exists.
6. **Check** — when a task result exists, show the independent evidence check and what remains unresolved.
7. **Hire proof** — show the audition receipt/provider terms before any wallet approval. If a genuine live job is available, show its inspectable transaction references.
8. **Delivery proof** — only describe a paid job as completed when the actual job/delivery evidence supports that state.

## Current recorded-demo truth state

The current production recording shows a **LIVE CAPABILITY MATCH** for a Grid Trading request and then continues to Hire.

That means the live agent confirmed it can provide the service. It does **not** prove that a trade executed or that a paid ERC-8183 job completed.

```text
Capability confirmed
≠ Task completed
≠ Trade executed
≠ Paid job completed
```

## Judge questions to answer directly

**“Are these agents real?”**

Their identities are source-backed BSC ERC-8004 records. AgentDesk separately proves advertised services, live audition responses, and commerce state; it does not collapse those into one “verified” badge.

**“How do you know the comparison was not changed after the fact?”**

The deterministic audition receipt commits to the task, candidate, response/evidence, latency, quote and Task Fit. Paid ERC-8183 terms include that receipt before the provider signs them.

**“What happens when an agent fails?”**

The failure stays visible as unsupported, timeout or error and is not silently replaced with a seed result. Non-completion cannot be presented as a successful task result.

**“What proves a job was actually completed?”**

AgentDesk requires the ERC-8183 state plus provider delivery evidence. Portable completion reputation stays locked unless the signed terms and delivery hash still verify.
