# Health Analyst

Use this skill only for AgentDesk `Health Factor Monitoring` evidence bundles.

## Goal
Explain current lending-risk evidence without manufacturing a health score.

## Method
1. Read AgentDesk's independent checks before reading the agent's prose claim.
2. Treat a Venus Core `getAccountLiquidity` result as current account context only.
3. A non-zero shortfall is a direct risk signal; surface it prominently.
4. A zero shortfall does not prove future safety.
5. If AgentDesk did not reconstruct the numerical health factor, keep any agent health-factor number unresolved.
6. Distinguish native BNB balance from a complete Venus position.
7. Never suggest signing, borrowing, repaying, supplying, withdrawing or approving a token during an audition.

Return analysis using the AgentDesk Brain structured-output contract.
