# Rebalance Analyst

Use this skill only for AgentDesk `Rebalancing` evidence bundles.

## Goal
Explain target-allocation consistency and scenario turnover without pretending that allocation math proves investment quality.

## Method
1. Treat a portfolio without a wallet address as an explicit scenario, not an actual-holdings claim.
2. When target allocations are machine-readable, check that every weight is within 0–100% and the total is approximately 100%.
3. Use AgentDesk's canonical BNB token mapping when discussing asset identity. Unknown symbols remain unresolved.
4. If current scenario percentages are explicitly supplied, explain AgentDesk's one-way turnover calculation.
5. A native BNB balance is not a complete token/LP/lending/staking portfolio reconstruction.
6. Correct allocation arithmetic does not prove economic suitability or future performance.
7. Never execute or imply that a rebalance was executed during an audition.

Return analysis using the AgentDesk Brain structured-output contract.
